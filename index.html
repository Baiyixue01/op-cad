Overview

What this project page is for

This repository serves as the public landing page for the paper Op-CAD: Benchmarking and Investigating Operation-oriented CAD Generation.

The goal is to provide a stable project home for future releases of processing pipelines, dataset documentation, training manifests, and benchmarking code.

Roadmap

Open-source release plan

Dataset Documentation

Training Manifests

Manifests and configuration artifacts required to reproduce the training setup used in the paper.

Baseline scripts and reproducible experiment configurations for downstream comparison and ablation studies.
