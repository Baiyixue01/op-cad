The benchmark

From final geometry to the full modeling chain.

Op-CAD decomposes modeling sequences into explicit operations and pairs them with geometry-guided hierarchical annotations. It supports evaluation at both geometric and spatial levels, including the CF-IoU metric for chamfer and fillet operations.

What is included

A dataset, parser, metric, and reasoning strategy.

01 / DATA

Operation-oriented dataset

High-quality multimodal examples expose both the current operation and its role in the full procedural history.

02 / ANNOTATION

Geometry-guided pipeline

A CAD parsing module and hierarchical annotation pipeline produce fine-grained operation and topology descriptions.

03 / EVALUATION

Decoupled evaluation

Geometric shape and spatial localization are evaluated separately, with CF-IoU for chamfer and fillet operations.

04 / PROMPTING

Chain-of-Operation

COOP prompting follows an engineer-like sequence of operation planning and spatial reasoning.

05 / MODEL

OP-Llama-8B

The released instruction model is fine-tuned for operation-oriented CAD code generation and can be served with vLLM.

06 / REPRODUCIBILITY

Open release

Code, dataset, weights, rendering utilities, and the official paper are linked as a single reproducible release.

Public release

Build, inspect, and evaluate Op-CAD.

The dataset release includes operation-oriented render metadata, normalized point clouds, and CSV/JSON benchmark metadata. The companion repositories provide evaluation and data rendering code.
