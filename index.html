Overview

Research home for the paper

This page is the public project homepage for Op-CAD: Benchmarking and Investigating Operation-oriented CAD Generation.

It is intended to host a stable set of links for the paper, dataset, model release, training manifests, and evaluation code.

The design language follows a CAD-oriented engineering style rather than a generic landing page, with emphasis on structure, clarity, and release status.
